# ProjectDesk for Windows

Project and subcontract management for Emirates International Projects and Prime Engineering Projects.

Download the latest Windows ZIP from **Releases**, extract all files into a folder and open **ProjectDesk-v2.exe**. Keep the program files together.

Open **Settings & local data → Software updates** to check for updates or install a downloaded version. No update account or sign-in is required. Updates also download automatically and install after ProjectDesk closes.

Company records and documents stay in the local **Data** folder. Program updates preserve that folder and create a data backup before installation.

This repository contains application downloads and signed update manifests.
